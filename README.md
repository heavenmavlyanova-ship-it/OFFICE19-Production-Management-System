# OFFICE19 — Pharmaceutical Production Management System

## Project Overview

OFFICE19 is a pharmaceutical production management system developed to support real-world manufacturing operations. The project focuses on improving production visibility, monitoring performance, and organizing operational data.

## Key Features

- Production planning and monitoring
- Planned vs. actual production tracking
- Batch and production-stage tracking
- Shift performance comparison
- Rejected quantity monitoring
- Production dashboards and reports
- CSV data export
